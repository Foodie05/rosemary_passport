# 认证界面视觉与移动布局修正（0.11.1）

日期：2026-11-15。依据固定的 Rosemary Forma 1.3 / SDK 0.5.0：同组控件的文字基线、字号与内边距一致；使用完整语义角色、官方控件和交互生命周期。产品补充要求为窄屏网页、竖屏 SDK 不使用外层卡片，弹窗保留明显边距与适当体量。

## 验收标准和修正

| 检查项 | 修正与实际检查 |
| --- | --- |
| 页面构图 | 桌面维持内容定高、纵向居中的单一卡片，左侧不装进容器。网页 1023px 以下直接用画布；480px 内容上限用于平板，工具、表单和页脚同边界。SDK 竖屏或窄窗口使用画布和顶部布局，宽裕横屏保留居中卡片；注册、恢复、MFA、授权也遵循该规则。 |
| 协议和辅助操作 | 网页协议普通文字、链接、“与”和版本使用同一 14px/24px 行盒；链接与普通文本共享基线，复选框对齐第一行。连接词跟随下一条协议，版本不拆成孤字。注册提示、链接、保持登录和忘记密码共用辅助字号，阅读顺序和边界明确。SDK 使用同样的行高、原生行内链接和 SDK 复选框，并保留普通文字点击与独立键盘链接。 |
| 字段及图标 | 复查标签、框体和提示的左边界，删除空 verification 的多余留白。网页密码眼睛居中于输入框；图标按钮固定 44×44 且图标居中。SDK 将 20px 图标置于 44px 槽内，防止前缀被约束拉大；填充按 8px 裁切，轮廓仍用已校验官方实现。 |
| 按钮和文字 | SDK 文本使用固定 Rosemary 字体族，避免任意宿主字体混入；次按钮与文字操作内容居中。全宽主按钮用公开 SDK 子类纠正内容行对齐，保留原动作表面、加载、语义和尺寸令牌。实际渲染发现并修正了控件文字偏上和主按钮内容靠左问题。 |
| 弹窗 | 网页至少保留左右 20px、上下 24px，并受 680px / 可见视口 84% 的高度上限约束；紧凑确认宽度最多 440px，其他普通弹窗最多 520px。监听 visualViewport，在键盘或窗口变化时更新可用区域。SDK 保留安全区及键盘外边距，使用有界内容和内部滚动；不把键盘高度塞进内容制造空白。 |
| 生命周期 | 网页继续由官方模态管理焦点和退出，根滚动锁及视口变量在退出完成后恢复。SDK 边界适配保留原有主题快照、焦点圈定/恢复、返回/外部关闭和动画完成回调。减少动态保持生效。 |

视觉验收包括层级、阅读顺序、密度、换行、对齐、控件几何和明暗表现；“可打开 / 无整页溢出”只是一项基本条件，不能代替上述检查。

## 覆盖范围与证据

- 实际 Web 组件：登录、注册、找回密码、账户、看板、用户、状态、服务、安全、应用、协议管理、OIDC 文档、Flutter 文档、条款与封禁页，共 15 类；1440px 浅色、320px 深色共 30 组控件几何记录与截图。另检查 390px、768px 的工具/内容边界，以及独立授权页的 320px/768px 无框布局。
- 单独复查密码方式的眼睛图标、协议首行/续行与注册提示基线；长内容重置弹窗在 320×480 中宽 280px，高约 403px，左右各 20px、上下约 38px，内容在内部滚动。协议确认 390px 下宽 350px，左右各 20px。
- 既有实际 App / 模拟 API 验收在桌面和窄屏各 26 项通过：方向切换、淡入淡出、线性高度、快速中断、减少动态、焦点隔离、验证码路由、协议版本和返回操作均保留。
- Flutter：61 项测试通过；新增协议基线与键盘链接、无框竖屏、横屏卡片、原生图标尺寸、主按钮居中、长内容滚动、弹窗打开后键盘缩小可用区、关闭后焦点恢复。既有 320px、200% 字体、明暗、IME/autofill 与 MFA 焦点回归继续通过。
- Web 74 项测试、生产构建；Flutter 静态分析、官方来源校验；后端分析及授权页回归通过。生成源与正式 CI 在提交后继续校验。

原生截图来自 Flutter widget 渲染器，本地加载系统中英文正文字体及 Georgia 以检查实际字形，不随包分发字体文件。不是实体 iOS/Android、VoiceOver/TalkBack 或真实第三方 CAPTCHA 的验收声明。浏览器使用合成账户、无效力协议和模拟请求，没有创建、授权或修改生产账户。

## SDK 来源边界

官方归档、23 个展开文件及许可证保持不变。原生公开接口没有富文本复选框标签、弹窗边界或全宽按钮内容对齐参数；Epass 分别使用原生行内文字组合、固定源派生的弹窗边界适配、公开按钮子类。两个派生器和 `check_rosemary_sdk.py` 校验允许的差异；派生器仅变更有界布局，其余交互与固定源码保持一致。轮廓、选择、加载、模态生命周期仍由同源实现提供。

本次仅变更布局、排版与本地控件组合，不新增数据库迁移，不重置用户数据、会话或凭据。SDK 以新 `v0.11.1` 标签交付，保留 `v0.11.0` 和此前历史。
