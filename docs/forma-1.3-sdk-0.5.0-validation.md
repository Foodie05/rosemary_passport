# Forma 1.3 / SDK 0.5.0 适配与验收记录

日期：2026-11-13。上游为 [v0.5.0 正式发布](https://github.com/Foodie05/Rosemary-Design-System/releases/tag/v0.5.0)，源提交 `340d2f4531ea0f1e16d62537b02124e5823d8fa2`。规范依据为该提交的 `docs/standards/forma-1.3.md`、`docs/sdk/0.5.0-migration.md`、`docs/sdk/input-validation.md` 和交互契约。

## 来源与可复现构建

- Web 的 tokens、icons、React 均使用官方 0.5.0 发布 tgz，固定本地相对依赖和 npm integrity；保留官方 SHA256SUMS、release manifest 与 MIT/品牌条款。
- Flutter 产品包适配版本为 0.11.0，设计依赖为官方 `rosemary_ui` 0.5.0。原始发布归档与展开源码保存在 `packages/rosm_passport_flutter/vendor`。`scripts/check_rosemary_sdk.py` 验证归档 SHA256、全部展开源文件（库的解析锁文件只保留在原始归档内）以及输入轮廓适配器的实现一致性。
- 绿调主题由官方 HCT `generateColorRecipe({seed:'#315747',mood:'calm'})` 生成；不手工拼接旧 24 色，不使用平台近似种子算法。每种模式均为 45 个完整角色，56 组官方对比度关系均通过。
- `python3 scripts/sync_epass_tokens.py` 先调用官方配色生成器，再同步 Web CSS、Dart/Flutter tokens、静态文档、品牌衍生图和默认邮件。`web/src/design/manifest.json` 记录来源、校验和、产品品牌例外与命令。

## 已适配内容

| 规范要求 | 实现 |
| --- | --- |
| 导航、顶栏、内容组、内嵌与浮层分别使用语义角色 | 配对主题注入官方 provider；侧栏和移动抽屉共用导航色，顶栏使用独立颜色与控件色 |
| 1480px 内容上限、统一响应式外边距与 76px 顶栏 | 页面容器统一；侧栏独立滚动并阻止边界串动；表格、代码保留内部滚动提示 |
| 克制分隔线 | 用户表、冷却表和应用列表通过浅深交替底色区分行；表头、行、分页和徽标不画装饰线。账户列表、统计组与内容组同样使用色差和留白；封禁原因、警告、通知等提示卡片仅用语义底色表达状态 |
| SDK 控件与默认尺寸 | Web 按钮、输入、搜索、表格、分页、徽标、复选框、选择器和弹窗消费官方组件；去除重复输入框描边、额外按压缩放和旧图标依赖 |
| 字段首次非空失焦后校验 | 使用官方 requirements 与校验状态；空值中性，激活后实时更新，组合输入期间延迟，清空恢复中性 |
| 验证操作和反馈邻接字段 | 验证码发送、注册内嵌 CAPTCHA、异步验证结果与原生表单错误使用字段下方 verification 区域；过期字段不接收异步结果 |
| 8–32 位新密码 | Web/Flutter 调用官方纯检查器；后端校验相同规则。仅 U+0021–U+007E、至少两类、不含空格，不改写原始密码；保留已有弱密码防护 |
| 旧凭据兼容 | 登录不套用新建复杂度；长密码、Unicode 和历史弱密码哈希验证保留测试 |
| 单个明暗切换入口 | 至少 44×44，名称与图标描述切换目标；默认跟随系统，显式选择后保存；无占位语言选择 |
| 动效与减少动态 | 由官方组件执行按钮物理反馈、轮廓与浮层；宿主不叠加缩放。弹窗只锁根滚动，在真实退出完成后释放，顶栏不移动 |

Web 0.5.0 的 Drawer 未提供 placement 属性。导航使用同源起始侧适配器，保留官方原生模态、焦点圈定、退出回调与动效，只调整起始侧方向，并通过发布源码一致性校验。LTR 从左侧展开，RTL 对应右侧；贴边直角，游离边缘圆角。

Flutter 的公开输入组件没有 controller、autofill 与 textInputAction 参数。需要这些能力的字段保留原生编辑器，通过官方主题、requirements 和验证状态适配。轮廓实现仅从已校验发布源码替换类名及私有导入，几何和时序保持一致，并保留 MIT 署名；其他依赖均走公开 SDK 导出。选择范围、IME composing 和密码管理器/OTP 提示保留。

静态授权、错误、维护文档不加载 React 运行时，采用同一生成主题、几何和原生表单语义；邮件采用相同浅色角色的内联样式。阿里云弹出式安全验证由提供商 SDK 控制，保留其交互，宿主的等待、失败和恢复信息放在字段旁。没有替换或绕过实际 CAPTCHA。

## 验证结果

- Web：67 项 Node 测试通过；Vite 8.2.4 生产构建通过；npm audit 无漏洞。包含旧 CAPTCHA 重试、状态管理、来源校验、完整主题及异步反馈隔离回归。
- Flutter：分析无问题，75 项可见测试通过（包含官方 vendored SDK 测试），无跳过；覆盖 320px、200% 字体缩放、主题对比度、失焦/清空、IME composing、autofill、原生 MFA 与冷却行为。
- 后端：分析通过；161 项可见测试通过，无跳过。PostgreSQL 集成使用独立的内存临时容器，先装入仓库测试快照，包含历史数据兼容、审计、OIDC、会话和冷却记录回归；未连接生产库运行测试。
- 浏览器：实际组件夹具覆盖账户、看板、用户、服务、安全、OIDC、状态、协议管理、两种接入文档、条款、封禁页和注册页。1440px 浅色与 320px 深色巡检均无整页横向溢出，管理台顶栏为 76px；认证页后续按产品要求取消横栏，将 Logo 与明暗控件、圆角主容器和无分割线页脚统一对齐。
- 浏览器交互验收全部通过：单一活动表单、动效中断和反向、真实弹窗/抽屉进入退出、焦点恢复、减少动态、延迟 loading、快速导航和路由焦点。另检验注册字段的中性→失焦判错→清空中性、桌面弹窗与 390px 导航抽屉的根滚动恢复，以及读取失败→成功→再次失败时不冒充空列表。

这些结果不代表已经完成 Safari、VoiceOver/TalkBack、全部最低系统与真实 iOS/Android 设备认证；实际第三方 CAPTCHA 验证也未作为自动化测试执行。后续验收应记录具体设备、系统和辅助技术版本。

## 数据与发布边界

本次不增加、改写或删除数据库迁移，不更新用户、会话、密钥或冷却记录。初始化 SQL 只更新新安装默认邮件；已有精确匹配旧默认邮件的内容在读取时转换显示，数据库原值和自定义模板保留。回滚代码无需恢复数据库。Flutter 接入文档使用适配分支，未把尚未发布的 0.11.0 标签表述为已发布。
