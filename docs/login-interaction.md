# 登录入口与切换交互

登录入口为「验证码」「通行密钥」「密码」三种。验证码页使用一个「手机号或邮箱」输入框，本地判断邮箱或后端支持的大陆手机号（含 +86、86 前缀及空格、连字符、括号），再调用原有手机或邮箱验证码接口。无效输入就地反馈，不发送验证码、不查询账号是否存在。验证码校验、MFA、注册接续、CAPTCHA、当前协议版本及记住登录状态保持原有后端契约。切换回验证码时重新将输入同步至对应请求字段，避免密码页编辑邮箱后发错收件人。

无当前登录用户时隐藏「切换账号」。验证码步骤保留修改输入的返回入口。协议与记住登录状态之间使用 8px 间距，登录模块段落使用 24px 间距。

「忘记密码？」独立显示，不带说明小字或箭头。只有带有合法站内 `/oidc/continue?client_id=…` 接续目标的第三方授权登录，才在同一行右侧显示无箭头的「账户中心」。本站账户登录不显示此入口。

Tab 指示线平滑移动；登录内容使用 Forma tabs 时长与标准曲线双向平移。右侧标签进入时，新面板从右进入、旧面板从左退出；反向切换时方向相反。登录表单顶部固定对齐，避免垂直居中在窄屏跨越最小高度时引入额外位移。占位高度在同一时长内线性插值，让下方静态模块连续腾出或收回空间。快速切换会取消旧动画并接续当前高度；退出视觉快照为 inert、aria-hidden，无重复 ID、无可提交交互，也不保留密码值。减少动态时立即切换，不做平移或高度动画。其他页面原有 SelectionContent 行为保持不变。

邮箱字段移除常驻格式示例，仍通过 SDK 公开的 useFieldValidation 在首次非空失焦后显示格式错误，支持 IME，清空后恢复中性。

验证：Web 71 项测试及生产构建通过。`web/tests/browser/legal-consent.html?clean=1&checks=1` 使用实际 App 与全量模拟 fetch，23 项浏览器检查覆盖双向/中断/减少动态、线性高度中点、退出输入不可聚焦、格式反馈、手机号规范化及两个原有验证码登录接口。仅使用本地虚构账号、协议和验证码，不调用真实 CAPTCHA、短信或邮箱。另巡检 1440px 浅色与 320px 深色，以及 `?clean=1&oidc=1` 下账户中心与忘记密码同行、右对齐且无箭头。
