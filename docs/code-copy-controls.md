# 文档代码复制

OIDC 与 Flutter 文档共用的代码示例去除边框，用语义 surface-inset 底色区分。右上角固定工具栏使用官方 SDK IconButton，代码仍可横向滚动，复制按钮不随长行滚走。

代码复制和「复制为 MD」共用 CopyButton。复制成功后图标从 copy 变为 check，持续 1.6 秒后恢复；再次复制会重新计时。屏幕阅读器同步收到成功状态，失败时不会显示对号，并提示手动复制。优先使用浏览器 Clipboard API，不可用时使用受用户操作触发的原生回退，检查实际返回值并清除临时元素、恢复焦点。只复制对应代码原文或完整 Markdown，不把按钮文案混入剪贴板。

复制进行中阻止重复请求；卸载时清理定时器，文档内容变化时清理旧反馈。Web 测试覆盖精确文本、回退、失败及焦点/临时元素清理。
